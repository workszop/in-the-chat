# Inside the Chat

An interactive, single-file educational simulation explaining how AI chat systems work — tokenization, embeddings, attention, generation, memory, hallucinations, prompt engineering, RAG, and training/alignment.

Open `simple_app.html` directly in a browser, or serve it locally:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000/simple_app.html`.

Bilingual (Polish default, English toggle). No build step, no dependencies, no external API calls — everything runs client-side.
